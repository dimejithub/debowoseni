FAQ

          
Questions, answered

        

        

          

            Is this actually free?
            
Yes. Distil runs entirely in your browser — there's no account, no paywall, and no server storing your data. Paste a URL and go.

          

          

            How does it read the website?
            
When you submit a URL, Distil fetches the page's public HTML (through a read-only proxy to sidestep browser CORS limits) and parses the markup locally to extract structure, design, content, and tech signals. If a site blocks fetching, you can paste the page source manually for a fully offline analysis.

          

          

            Will the prompt perfectly recreate the site?
            
It captures the vibe — layout, hierarchy, palette, type, and messaging — not a pixel-perfect copy. Think of it as an expertly-written brief you refine, not a screenshot. That's usually a better starting point for AI tools than "clone this exactly."

          

          

            Which AI tools does it support?
            
Any tool that takes a text prompt. We include one-click presets for Cursor, Claude, v0, Bolt, Lovable, and ChatGPT that adjust the framing and instructions to match each tool's strengths.

          

          

            Is it okay to clone other people's sites?
            
Use Distil for inspiration, learning, and starting points — not to copy branding, copy, or proprietary assets wholesale. Respect trademarks, content, and each site's terms. You're responsible for what you build.
